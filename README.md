# Story Manager

Aplicación para escribir y organizar libros interactivos y sus posibles caminos.

Este repositorio se destina a las descargas del programa compilado y a las
novedades de cada versión. El código de desarrollo se mantiene en un
repositorio privado independiente.

## Versión portable

Story Manager funciona en Windows 10/11 de 64 bits. No necesita instalador
ni Python instalado. Mantén la carpeta `_internal` junto a `Story Manager.exe`.
Puedes guardar tus historias `.pkl` donde prefieras.

La consulta de la RAE necesita Internet. La exportación `.odt` no necesita
Microsoft Office. La exportación mediante Word necesita Microsoft Word instalado.

## Descargar

[Descargar Story Manager v3.1 para Windows de 64 bits](https://github.com/JoseTamayoMaluenda/story-manager-releases/releases/download/v3.1/Story_Manager_v3.1_Portable_windows_x64.zip)

Extrae el ZIP completo en una carpeta y abre `Story Manager.exe`.

[Novedades y archivos de comprobación de la v3.1](https://github.com/JoseTamayoMaluenda/story-manager-releases/releases/tag/v3.1)

Para actualizar una copia existente, guarda la historia y cierra el programa.
Sustituye el ejecutable y `_internal`, conservando las historias `.pkl` y tu
`configuracion.json`.
El sistema de actualización desde la aplicación está pendiente de implementar.
